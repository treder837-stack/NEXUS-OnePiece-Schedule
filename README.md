# NEXUS — Grand Line Schedule

Anime-inspired weekly planner with editable daily missions, XP, levels, streaks and a daily challenge.

## Try it in Chrome
Enable GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**. Then open:
https://treder837-stack.github.io/NEXUS-OnePiece-Schedule/

## Android APK
Open **Actions → Build NEXUS Android APK → Run workflow**. When complete, download the `NEXUS-debug-apk` artifact from the run.

## Notes
- Schedule data is stored locally on the device/browser.
- This fan-made planner uses an original pirate-themed interface and does not include official anime artwork.
